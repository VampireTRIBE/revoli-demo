# Bizcom Engine | 25 November 2026 update

Baseline: `Bizcom-Engine-Creative-Brands-UnionCoop-Media-Full(1).zip`. Requirements: the supplied 18 November PDF (identical SHA-256 to `docs/requirements/Bizcom-Engine-Changes-Simple-18-Nov-2026.pdf`). This is a full source-project archive, not just a patch. Original data and assets are retained. The six supplemental Rivoli workbooks in the separately supplied `data.zip` are byte-identical to the workbooks already present in the project; importing them again would duplicate evidence.

## Changes made

- Media filter option queries now use reporting **year**, not reporting month. Brand options are dependent on selected segment(s); monthly metrics, history and campaign filters remain separate. Preserve valid filter choices when switching months, clear brand on segment change, preserve unrelated URL parameters and expose API retry on option errors. Brand and segment options are alphabetically sorted. Year selection can explicitly be All Years. October has GA4 data but no matching monthly spend/segmented site source, so selecting a brand does not manufacture October performance.
- Removed `(partial)` suffix from Media, Creative and Consumer month dropdowns. Partial coverage remains in data and reporting context; incomplete September paid reporting is still Jan-Sep source coverage, not a complete September export.
- Campaigns: explicit Objective column has provenance on hover. Google campaign names with an unambiguous explicit objective token are classified from the source name (not asserted to be an imported objective column). Explicit Objective field, if present, takes precedence; Meta uses its documented Stage mapping. Unknown or conflicting objectives stay unranked. Cost rankings are separated by objective, platform and result measure in both the preview and full searchable register. Awareness uses views/impressions and never conversions. Source short names and images are preferred; absent short names use a clearly labelled abbreviation of the source name and the full string is accessible on hover. Missing thumbnails remain unavailable rather than borrowing competitor/stock images. A separately labelled year register is available when a month has no campaigns; it is not selected-month results.
- October missing spend and acquisition metrics use compact awaiting lines with owners rather than empty large cards. Platform table missing coverage is labelled for the selected month rather than implying a full-year table. Complete new-customer CAC and revenue coverage require complete platform coverage, matching time windows and site-wide denominators. Brand-filtered spend is not mixed with site-wide GA4 revenue; channel data explicitly identifies site-wide context. Legacy whole-site spend cannot leak into a filtered history.
- Compare-against is now offered on all existing navigation pages, following the new request to check the PDF's every-head instruction. Media and Consumer use their selected client; Search uses Union Coop, and the unimplemented generic pages use the existing Rivoli client context. Creative brands other than Union Coop have an Off control but no mapped competitors. Competitor panels remain visibly separate from own performance with a dark source strip and activity-not-spend label. The generic pages are still awaiting own data, not completed business/technology dashboards.

## Source inventory and validation

`NOV25_SOURCE_INVENTORY.json` inventories 23 XLSX files (including archival copies), 61 CSV files and one thumbnail ZIP by SHA-256. File inclusion is not a claim that every archival/supplementary export is a separate live dataset. Original source mappings and override checks were re-run. Actual CSV parsing and account aggregates were exercised by `verify_brand_reference_update.cjs`. `verify_nov25_media_regression.cjs` executes the actual TypeScript media parser and analytics against actual workbook cells via a lightweight openpyxl adapter and a deliberately unavailable database. It found 14 segments, 8 Swiss brands, 63 aggregated Google campaign names, and two null October platform spend values. It does not exercise SheetJS itself, MongoDB, HTTP middleware or the React browser.

All 16 `scripts/verify_*.cjs` scripts exited successfully. Some are static source contracts, others execute calculation and parsing functions. Existing scope checks were updated to the current PDF's every-head requirement. 131 TypeScript/TSX files passed syntax transpilation. Full semantic compilation, real Express/Vitest integration, lint and browser tests were **not** executed: offline npm installation failed ENOTCACHED for zod 4.6.5; online installation failed with npm's exit-handler error. No `node_modules` is shipped. Run `npm ci`, `npm run build`, `npm test` and `npm run dev` locally. New optional workbook-cell regression uses Python openpyxl plus TypeScript; `node scripts/verify_nov25_media_regression.cjs` after installation runs it.
